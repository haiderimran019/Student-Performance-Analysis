About this dashboard · associations, not causes

What it explores

Patterns in math, reading, and writing scores across demographic, education, lunch, and test-preparation groups.

How to use it

Use the filters to compare groups. The cards, charts, and table update to reflect the students currently shown.

Interpret with care

This dashboard shows associations in this dataset; it does not establish that any factor causes student performance. Lunch type is only an approximate proxy, not a complete measure of socioeconomic status.
